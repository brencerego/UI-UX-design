Hospital Management System

A smart and impactful hospital management web application designed to address challenges in healthcare, such as paperwork, complexity and communication delays. Rock Paper Scissors Game

Developed a Rock Paper Scissors game where the user plays against the computer. It uses Python for the backend and HTML, CSS and JavaScript for the frontend. The player chooses rock, paper or scissors while the computer randomly selects its choice. The result (win, loss or draw) is displayed based on the game rules, along with a scoreboard tracking the player's and computer's wins.


Supermarket Database

Created a Supermarket Database Management System using MySQL and Python. It stores and manages supermarket inventory, including Item ID, Item Name, Item Company, Item Type and Production Date. Using Python's MySQL connector, users can add, update, delete and retrieve item records efficiently. It provides a simple way to manage inventory.
